# 观点演变时间线

想追踪一个观点从"争议"到"共识"的完整演变过程？
**可视化时间线帮你看清舆论场的暗流涌动。**

[![HTML](https://img.shields.io/badge/打开即用-无需安装-orange)]()

## 一眼看透观点演变

- **多人对比**：2-4人观点轨迹，SVG节点图直观呈现
- **节点溯源**：每个观点节点关联原始链接
- **一键导出**：html2canvas生成图片，方便分享
- **时间线编辑**：添加/编辑/删除节点，自定义轨迹

## 怎么用

打开 `web_timeline.html` → 添加观点节点 → 导出图片
